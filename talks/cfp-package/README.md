# Talk package for future submissions

A reusable description of the "Agent sprawl" talk for calls for papers: the abstract, what the
demo proves and what it doesn't (`EVIDENCE.md`), a run of show (`FUTURE_CFP_GUIDE.md`) and how
the claims are verified (`VERIFICATION.md`). It also covers publisher fix #2897, which the Paris version
([`../cloud-native-paris-2026`](../cloud-native-paris-2026)) leaves out.
