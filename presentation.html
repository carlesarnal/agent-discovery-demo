Use the fictional multilingual briefing as a small, concrete illustration.

Three separate responsibilities

  • Registry: published definitions and endpoint discovery.
  • Application: required roles and handoff order.
  • Runtime: execution and actual behavior.
None automatically guarantees the other two.

A2A and MCP in the same workflow

MCP getWeather(city)
  → A2A summarize(weather + context)
  → A2A translate(summary)

Fixed sequence. Discovered endpoints. Actual outputs passed forward.

Not autonomous planning or capability negotiation.

Use the registry extensions

  • Text agents publish through the A2A extension's programmatic publisher.
  • The runner registers the Weather MCP artifact and connection labels.
  • ApicurioAgentsRegistry supplies callable agents.
  • The MCP extension searches, connects and invokes the tool.
Application code fixes the handoff order. Distinguish explicit MCP registration from automatic ingestion.

Keeping another skill separates compatibility rejection from a generic empty-card validity failure.

Check what stayed unchanged

  • Accepted card content.
  • Latest registered version and globalId.
  • A complete briefing still runs.

Then publish an additive change and observe the new registration.

Adding a metadata skill does not implement it in the running agent. Explain exactly what this test proves.

What the tests establish

  • MCP output reaches the summarizer; its output reaches the translator.
  • Missing required agents stop the workflow.
  • Incompatible publication preserves the accepted registration.

They do not evaluate all generated language or prevent runtime drift.

Unit tests use mocks; the separate smoke runner makes real calls. Keep the two forms of evidence distinct.

What remains application work

  • Deployment checks and behavioral evaluation.
  • Authentication, authorization and tenant isolation.
  • Version pinning and consumer lifecycle policy.
This sample has no deprecation gate. Local-only, unauthenticated demo.

Takeaways

  • Discover endpoints without hardcoding network locations.
  • Make agent/tool handoffs explicit and testable.
  • Verify what a rejected contract update preserves.
  • Keep metadata compatibility separate from runtime correctness.
