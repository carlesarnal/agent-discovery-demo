The Problem


Team A updates a prompt template.

Team B's agent silently breaks.


Sound familiar?


APIs went through this. Kafka schemas went through this.
Now AI agents are hitting the same wall.

What Breaks Without Governance


  • Discovery — How does Agent B find Agent A?
  • Versioning — Which version of the prompt is Agent C using?
  • Compatibility — Will Agent D break if we add a field?
  • Lifecycle — When can we retire an old agent?

The tooling for APIs exists. For AI agents, it hasn't caught up. Until now.

The A2A Protocol

Agent-to-Agent Protocol by Google


  • Standardized Agent Cards — structured capability declarations
  • Skills with typed input/output modes
  • Capability flags (streaming, batch, push notifications)
  • Designed for discovery via /.well-known/agent.json

But well-known requires knowing the host first.

Registry-backed discovery lets you query by capability.

A2A Agent Card

{ "name": "Summarizer Agent", "url": "https://agents.internal/summarizer", "version": "1.0.0", "capabilities": { "streaming": true }, "skills": [{ "id": "summarize-text", "name": "Text Summarization", "inputModes": ["text"], "outputModes": ["text"] }] }

Registered in Apicurio Registry under the ai-agents group

Prompt Template Governance


ChangeCompatible?
Add optional variable (with default)Yes ✓
Remove a required variableNo ✗ — Rejected
Rename a variableNo ✗ — Rejected
Change model metadataYes ✓

BACKWARD compatibility rule: new versions must be consumable by agents using the previous version.

Demo: Prompt Versioning

./scripts/02-register-prompts.sh

  • v1: max_sentences + input_text
  • v2: adds optional tone with default "neutral" → accepted
  • BACKWARD compatibility rule catches breaking changes

Demo: Breaking Change Rejected

./scripts/05-breaking-change.sh

Attempt: rename input_text → content

Result: HTTP 409 — Rejected


The registry catches this before production, not after.

Same pattern that saved Kafka deployments from schema drift.

Key Takeaways


  • Schema registry principles apply directly to AI agent governance
  • A2A Agent Cards enable registry-backed discovery
  • Prompt templates need version control with compatibility rules
  • Apicurio Registry — CNCF sandbox, open source, cloud-native

The governance tooling for AI agents already exists. It just needed to evolve.
